# Deepak Gupta — QA Engineer

Portfolio for fintech QA: UPI, lending, cards, automation, and release checks. Copy comes from the resume in `src/data/portfolio.ts`. Date of birth is not published.

## Stack

- [Next.js](https://nextjs.org) App Router and React — static pages, metadata, and case-study routes
- TypeScript
- Tailwind CSS
- `next/font` — Fraunces, Source Sans 3, IBM Plex Mono
- Playwright — the site checks its own main paths

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run test:e2e
```

Open [http://localhost:3000](http://localhost:3000).

## Edit the copy

Public copy, case studies, phone, email, and the LinkedIn link live in `src/data/portfolio.ts`.

Set `NEXT_PUBLIC_SITE_URL` to the production URL so the sitemap and social cards use it.

## Deploy

The app is a standard Next.js project and deploys on Vercel, or any host that runs `npm run build`.
